# CROXER
Agentic AI service 'CROXER'

## 처음 실행하기

이 프로젝트는 React, TypeScript, Vite, CSS를 사용합니다. 초기 환경은 Node.js `26.13.0`과 npm `11.20.0`에서 확인했습니다. 팀원이 같은 환경으로 시작할 수 있도록 Node 버전을 `.nvmrc`에도 적었습니다.

GitHub에서 복제한 CROXER 폴더를 열고 아래 명령을 순서대로 실행합니다.

```sh
npm ci
npm run dev
```

실행 후 표시되는 주소를 브라우저에서 열면 `CROXER`가 보입니다. 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누르세요.

## 변경 확인

```sh
npm run lint
npm run build
```

새 기능은 `main`에서 작업 브랜치를 만든 뒤 PR로 합칩니다. 새 AI 대화에는 [협업 시작 가이드](docs/collaboration-guide.md)와 이번에 하고 싶은 일을 전달하세요.
