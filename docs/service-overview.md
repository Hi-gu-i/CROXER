# CROXER 서비스 한 장 요약

## 서비스 한 줄 정의

CROXER는 여러 역할과 활동을 병행하는 크로스 플레이어의 활동 맥락을 이어주고, 현재 활동과 상황에 맞춰 필요한 정보와 기능을 구성하는 **다이나믹 UI(Dynamic UI)**를 제공하는 Agentic AI 서비스입니다.

## 문제 정의

여러 활동을 병행하는 사용자는 활동을 전환할 때마다 흩어진 자료와 대화를 찾고, 이전에 어디까지 진행했는지 다시 떠올려야 합니다. 활동마다 필요한 정보와 도구가 달라 이를 찾아 화면을 오가는 부담도 발생합니다. 갑작스러운 일정 변화가 생기면 다른 활동에 미치는 영향까지 직접 확인하고 조정해야 합니다.

CROXER는 활동별 맥락을 기억하고, 현재 활동에 필요한 정보와 기능을 다이나믹 UI로 구성합니다. 반복적인 확인과 준비에 드는 부담을 줄여 사용자가 현재 활동에 집중하도록 돕습니다.

## 대상과 목표

학업, 콘텐츠 제작, 커뮤니티 운영 등 여러 역할과 활동을 병행하는 **크로스 플레이어**를 대상으로 합니다. 이미 수행하고 있는 다양한 활동을 관리하고 전환하는 데 어려움을 느끼는 사용자입니다.

활동을 바꿀 때마다 맥락을 다시 설명하거나 도구를 찾아다니지 않고, 해당 활동의 진행 상황과 목적에 맞게 구성된 화면에서 자연스럽게 일을 이어가는 것을 목표로 합니다.

## 핵심 가치

**활동이 달라져도 맥락은 이어지고, 다이나믹 UI가 현재 활동에 필요한 정보와 기능을 제공합니다.**

다이나믹 UI는 사용자의 활동과 상황에 따라 필요한 정보, 기능, 화면 구성이 달라지는 인터페이스입니다. 리서치 중에는 자료를 읽고 비교하는 구성이, 촬영을 준비할 때는 이미지 레퍼런스와 메모가, 러닝 중에는 시간·거리·페이스를 확인하는 구성이 중심이 됩니다. 각 활동의 목적에 맞춰 화면의 내용과 조작 요소가 달라집니다.

AI는 상황을 파악해 필요한 도움을 먼저 제안하고 위임받은 업무를 수행합니다. 사용자는 AI의 위임 수준과 알림 방식을 설정하며, 중요한 결정과 활동 전환의 주도권을 유지합니다.

## 핵심 기능

1. **활동 등록과 맞춤 설정**

   사용자는 관리할 활동을 등록하고, 활동 목표와 AI의 위임 수준을 설정합니다.

2. **현재 활동에 맞춰 구성되는 다이나믹 UI**

   홈에서는 브리핑에서 맨 위에 둔 활동을 중심으로 보여줍니다. 활동 화면에서는 AI가 파악한 맥락에 따라 리서치 자료 비교, 촬영 레퍼런스 확인, 러닝 측정 등 현재 목적에 필요한 정보와 기능을 구성합니다.

3. **맥락과 인터페이스를 이어주는 활동 전환**

   다음 활동을 시작할 시점에 역할과 활동의 전환을 안내합니다. 사용자가 전환하면 해당 활동의 자료와 진행 상황을 불러오고, 다이나믹 UI로 화면 구성을 바꿔 바로 이어서 수행할 수 있도록 돕습니다. 사용자는 현재 활동을 유지하거나 다음 활동으로 전환할 수 있습니다.

4. **필요한 순간의 AI 개입**

   승인 요청·일정 변동·마감 위험·협업 요청이 발생하면 상황과 대안을 제시합니다. 사용자의 일정과 작업 패턴을 고려해 조정을 돕고, 위임받은 업무는 백그라운드에서 수행합니다.

5. **하루를 살피는 브리핑과 리포트**

   브리핑으로 오늘의 예정된 활동을 확인하고 조정합니다. 리포트에서는 활동 결과와 반복되는 패턴을 돌아보고, 다음 계획에 반영할 피드백을 확인합니다.

## 사용자 핵심 여정

활동 등록·기본 설정 → 오늘의 브리핑 확인 → 현재 활동에 맞는 화면에서 작업 → 필요한 순간 AI 지원 확인 → 다음 활동의 맥락과 다이나믹 UI로 전환 → 활동 결과 돌아보기

예를 들어, 리서치 검토 중에는 사례 자료와 비교 내용이 중심인 화면을 사용합니다. 촬영 활동으로 전환하면 촬영 레퍼런스와 메모가 중심인 화면으로 바뀝니다. 갑작스러운 비로 촬영이 어려워지면 AI가 대체 장소나 일정 조정안을 제안하고, 이를 검토하는 데 필요한 일정 비교 구성을 제공합니다. 사용자는 상황에 맞게 구성된 화면에서 다음 행동을 선택합니다.

## 초기 구현 범위와 검증 방향

초기 버전은 **현재 활동 확인 → 활동 수행 → AI 제안 검토 → 다음 활동의 다이나믹 UI로 전환**하는 핵심 경험을 중심으로 구성합니다. 서로 다른 활동에서 정보와 기능의 구성이 어떻게 달라지고, 해당 활동의 진행 상황을 어떻게 이어가는지 확인합니다.

사용자가 해야 할 일을 빠르게 파악하는지, 활동 전환 후 맥락을 쉽게 되찾는지, 달라진 화면에서 필요한 기능을 쉽게 찾는지, AI의 개입 이유와 선택지를 이해하는지 검증합니다. 실제 계정 연동, 자동 실행 범위, 다이나믹 UI의 구성 기준과 화면별 동작, 기술 요구사항은 별도 [PRD](prd.md)에서 구체화합니다.
